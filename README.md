# Tulas International School — Homepage Redesign

A modern, responsive and animated homepage redesign for **Tulas International School (TIS)**, created as a Frontend Developer assignment.

The existing TIS website was used as a reference for branding and content. The homepage was redesigned with a focus on modern UI, smooth animations, responsiveness and clean React architecture.

## Tech Stack

* React.js
* Vite
* CSS Modules
* JavaScript
* ESLint / Oxlint

## Features

* Responsive navigation with mobile menu
* Modern animated hero section
* Custom interactive cursor on desktop
* Scroll-triggered section animations
* Scroll progress indicator
* Responsive academic and facilities sections
* Achievements and testimonials
* Admissions CTA
* Contact form with validation
* Responsive design for desktop, tablet and mobile
* Accessibility and reduced-motion considerations

## Project Structure

```text
src/
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Mohanasolasa/Netpuppys_Task.git
cd Netpuppys_Task
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL shown in the terminal.

## Production Build

To create a production build:

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```

## Quality Checks

The project was checked using:

```bash
npm run lint
npm run build
```

Both complete successfully without errors.
